# Toolsy 
### Your tools. Your workspace. Your way.
Toolsy is a Windows desktop application designed to bring useful utilities and gamertag tools together in one clean, modern workspace.
Built with Python and PySide6, Toolsy focuses on usability, customisation, efficiency and keeping your data under your control. One of its main functionalities is username searching, showing you available usernames based off your choice. More down below.
---
## Main Features
### Gamertag Tools
- Generate random four-letter gamertags.
- Generate clean, single-word names.
- Generate short gamertags based off preferences.
- Create stylised names using numbers and character substitutions.
- Check gamertag availability with a few clicks.
- Import gamertag lists from TXT files.
- Organise and manage discovered names.
### Proxy Management
- Support for HTTP, HTTPS, SOCKS4 and SOCKS5 proxies.
- Import and manage proxy lists.
- Check proxies and identify broken ones.
- Remove unreliable proxies.
### Watchlist
- Save gamertags for future monitoring.
- Automatically check watched names.
- View watchlist updates inside the application.
- Receive in-app notifications.
### Dashboard
- View overall statistics.
- Track valid and invalid results.
- Access bookmarked results.
- Keeps everything compact in one place.
### ustomisation & Settings
- Range of themes
- Compact mode.
- Custom keyboard shortcuts.
- Adjustable search settings.
- Will remember your window settings.
- Optional Windows startup.
- System tray support.
### Privacy & Data
- Local-first application design.
- Local data storage.
- Backup and restore functionality.
- No required hosted backend.
- No automatic updates.
